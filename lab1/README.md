1. Фабричный метод (Factory Method)
Этот паттерн используется для создания объектов без указания точного класса создаваемого объекта. В коде у тебя есть абстрактный класс FurnitureFactory, который определяет метод CreateFurniture(). Конкретные фабрики ChairFactory и TableFactory реализуют этот метод, создавая Chair (Стул) и Table (Стол) соответственно.

🔹 Как работает:
В Main() вызывается chairFactory.CreateFurniture(), создавая объект Chair, не зная точный тип объекта заранее.

2. Одиночка (Singleton)
Этот паттерн гарантирует, что у класса есть только один экземпляр, и предоставляет к нему глобальную точку доступа. В коде класс FurnitureWarehouse хранит статическую переменную instance и предоставляет к ней доступ через Instance.

🔹 Как работает:
При вызове FurnitureWarehouse.Instance создаётся единственный объект FurnitureWarehouse. Все последующие вызовы возвращают тот же самый объект.

3. Заместитель (Proxy)
Этот паттерн создаёт объект-заместитель, который контролирует доступ к другому объекту. В коде FurnitureProxy заменяет RealFurniture, добавляя предварительную логику перед вызовом Display().

🔹 Как работает:
При вызове proxy.Display() сначала выполняется код заместителя, затем вызывается realFurniture.Display().

4. Адаптер (Adapter)
Этот паттерн позволяет использовать несовместимые интерфейсы без изменения их кода. В коде FurnitureAdapter адаптирует PreciousFurniturePart, предоставляя метод CalculatePrice(), который использует GetPartPrice().

🔹 Как работает:
При вызове adapter.CalculatePrice() адаптер преобразует вызов метода в нужный формат.

5. Посетитель (Visitor)
Этот паттерн позволяет изменять объекты без изменения их кода. В коде PriceModifier реализует IFurnitureVisitor и меняет название мебели.

🔹 Как работает:
При вызове modifier.Visit(furniture) у объекта Furniture изменяется название.

6. Шаблонный метод (Template Method)
Этот паттерн определяет основу алгоритма и позволяет подклассам переопределять отдельные шаги. В коде FurnitureTemplate имеет метод Build(), который вызывает AssembleParts() и FinalizeBuild(). Классы WoodenChair и MetalTable переопределяют AssembleParts().

🔹 Как работает:
При вызове woodenChair.Build() сначала вызывается Сборка деревянного стула, затем Завершение сборки.
